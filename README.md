## 🎯 Campaña Activa: Últimas Semanas de Estudio (Solo Facebook en Anuncios)

Campaña diseñada para aprovechar las **últimas semanas del semestre académico y cierre de año escolar**, ofreciendo clases particulares, preparación intensiva para parciales finales y asesorías técnicas en matemáticas, física, ingeniería civil/estructural y programación.

**Regla de Canal**: Todas las imágenes, videos y textos públicos invitan al interesado a escribir **únicamente por Facebook (Messenger / Inbox)**. El número de WhatsApp (`(+57) 300 408 3940`) se comparte en privado dentro de la conversación de Facebook.
